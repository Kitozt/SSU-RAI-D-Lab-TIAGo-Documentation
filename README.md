# SANIR2RS
Socially Aware Navigation Implementation in ROS 2 and Robot Simulations

This project explores the development of a robot's capability to navigate through university environments, mainly hallways and classrooms, in a socially aware manner. Our goal is to train the robot, TIAGo, to move efficiently through spaces while detecting pedestrians to keep a safe distance from them in real time. Additionally, to keep the navigation or interaction smooth, it will define the unoccupied areas within the classroom and move to those areas, demonstrating context-aware decision-making. By combining navigation algorithms with environmental perception, the system aims to simulate realistic human-like movement patterns in shared indoor spaces. This will highlight the challenges of dynamic obstacle avoidance, spatial awareness, and adaptive behavior in semi-structured environments like universities. This project contributes to ongoing research in robotics by emphasizing safe and socially compliant navigation in everyday human settings.
